# BookSure - Deployment Checklist

Complete this checklist to deploy BookSure to production.

## Phase 1: Pre-Deployment Setup (Do This First)

### Database
- [ ] Create Neon PostgreSQL project
- [ ] Get `DATABASE_URL` connection string
- [ ] Test connection: `pnpm db:push`
- [ ] Verify schema created with `pnpm db:studio`

### Authentication
- [ ] Generate `BETTER_AUTH_SECRET`: `openssl rand -base64 32`
- [ ] Create Google OAuth app in Google Cloud Console
- [ ] Get `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`
- [ ] Add redirect URI: `https://yourdomain.com/api/auth/google/callback`
- [ ] Test auth locally: sign up at `/sign-up`

### Environment Variables
Create `.env.production.local` with:
```env
DATABASE_URL=postgresql://...
BETTER_AUTH_SECRET=...
BETTER_AUTH_URL=https://yourdomain.com
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
NEXT_PUBLIC_APP_URL=https://yourdomain.com
```

## Phase 2: Deployment to Vercel

### Via GitHub (Recommended)

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Ready for production"
   git push origin main
   ```

2. **Connect to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Select your GitHub repository
   - Click "Import"

3. **Configure Environment Variables**
   - In Vercel dashboard, go to "Settings" → "Environment Variables"
   - Add all environment variables from `.env.local`
   - Important ones:
     - `DATABASE_URL`
     - `BETTER_AUTH_SECRET`
     - `GOOGLE_CLIENT_ID`
     - `GOOGLE_CLIENT_SECRET`
     - `NEXT_PUBLIC_APP_URL` (set to your Vercel domain)

4. **Deploy**
   - Click "Deploy"
   - Wait for build to complete
   - Your app is live! 🎉

### Via Vercel CLI

```bash
# Install Vercel CLI
pnpm install -g vercel

# Deploy
vercel

# Add environment variables when prompted
# Or later: vercel env add

# For production:
vercel --prod
```

## Phase 3: Post-Deployment Configuration

### Google OAuth Update
- [ ] Update Google OAuth redirect URI to production domain
  - Old: `http://localhost:3000/api/auth/google/callback`
  - New: `https://yourdomain.com/api/auth/google/callback`

### Custom Domain (Optional)
- [ ] Go to Vercel project settings
- [ ] Add custom domain under "Domains"
- [ ] Update DNS records at your domain registrar
- [ ] Wait for DNS propagation (can take 24-48 hours)

### Better Auth Configuration
- [ ] Update `BETTER_AUTH_URL` to production domain
- [ ] Update `NEXT_PUBLIC_APP_URL` to production domain
- [ ] Clear browser cookies/cache if you see auth errors

### Testing Production
- [ ] Test sign up: `/sign-up`
- [ ] Test sign in: `/sign-in`
- [ ] Test Google Calendar connection
- [ ] Create a test appointment at `/book/test-slug`
- [ ] Verify email works if configured

## Phase 4: Optional Integrations

### Stripe Integration (For Payments)

1. **Create Stripe Account**
   - Go to [stripe.com](https://stripe.com)
   - Sign up or log in
   - Get API keys from Dashboard

2. **Add Environment Variables**
   ```env
   STRIPE_SECRET_KEY=sk_live_...
   NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...
   ```

3. **Configure Webhooks**
   - Go to Stripe Dashboard → Webhooks
   - Add endpoint: `https://yourdomain.com/api/webhooks/stripe`
   - Select events: `payment_intent.succeeded`, `checkout.session.completed`

4. **Set Webhook Secret**
   ```env
   STRIPE_WEBHOOK_SECRET=whsec_...
   ```

### Twilio Integration (For SMS)

1. **Create Twilio Account**
   - Go to [twilio.com](https://twilio.com)
   - Sign up and get phone number
   - Get Account SID and Auth Token

2. **Add Environment Variables**
   ```env
   TWILIO_ACCOUNT_SID=AC...
   TWILIO_AUTH_TOKEN=...
   TWILIO_PHONE_NUMBER=+1...
   ```

3. **Test SMS**
   - Create appointment at `/book/test-slug`
   - Should receive SMS confirmation

### Blob Storage (For Logos)

If you want to store logos in Vercel Blob:

1. **Enable in Vercel**
   - Go to project settings → Storage
   - Create Blob storage
   - Get token from `.env.local`

2. **Add to Production**
   ```env
   BLOB_READ_WRITE_TOKEN=...
   ```

## Common Issues & Solutions

### Build Failing
```bash
# Check for type errors
pnpm tsc --noEmit

# Check for lint errors
pnpm lint

# Rebuild dependencies
pnpm install
pnpm build
```

### Database Connection Error
- Verify `DATABASE_URL` is correct in Vercel env vars
- Check Neon dashboard for connection limits
- Restart Vercel deployment

### Google OAuth Failing
- Verify redirect URI matches exactly
- Check `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`
- Clear cookies and try again

### Booking Page Not Loading
- Check if database is connected
- Verify Google Calendar is actually connected
- Check logs in Vercel dashboard
